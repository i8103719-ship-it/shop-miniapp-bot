# VOID. — Telegram E-commerce Mini App

Полноценный интернет-магазин одежды внутри Telegram с корзиной, оформлением заказов и уведомлениями администратору. Дизайн выполнен в премиальном темном стиле (streetwear).

## Функционал:
- Красивый адаптивный интерфейс витрины (Mini App) с карточками товаров.
- Полноценная корзина: добавление, изменение количества, удаление и подсчет общей суммы.
- Сохранение корзины в `localStorage` (не сбрасывается при закрытии).
- Безопасное оформление заказа (запрос контактного номера через нативную кнопку).
- Защита от подмены цен (итоговая стоимость пересчитывается на стороне сервера).
- Мгновенные уведомления о новых заказах в Telegram администратору.

## Технологии:
- **Frontend:** HTML, CSS, JavaScript (Telegram WebApp API)
- **Backend:** Python, Aiogram 3
- **Деплой:** GitHub Pages (Frontend), Railway (Backend)
